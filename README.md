# ΦΥΣΙΟ — εφαρμογή v1

Τοπική εφαρμογή Flask + SQLite για Windows και Linux. Ο server ακούει μόνο στο
`127.0.0.1:5000`.

## Πρώτη εγκατάσταση

Windows: εκτέλεσε μία φορά το `setup_windows.bat`.

Linux:

```bash
chmod +x setup_linux.sh start_linux.sh
./setup_linux.sh
```

Τα scripts εκκίνησης δεν εκτελούν πλέον `pip install` σε κάθε άνοιγμα.
Οι ακριβείς εκδόσεις βρίσκονται στο `requirements-lock.txt`.

## Εκκίνηση

- Windows: διπλό κλικ στο `start_windows.bat`.
- Linux: `./start_linux.sh`.
- Άνοιγμα: http://127.0.0.1:5000

## Ασφάλεια δεδομένων

- Νέος ασθενής και νέο ιστορικό δημιουργούνται μόνο με «Αποθήκευση».
- Όλα τα API εγγραφής απαιτούν CSRF token και έγκυρες τιμές.
- Το Undo συνδέεται με τη συγκεκριμένη κλινική βάση και επιβεβαιώνεται πριν εκτελεστεί.
- Οι σελίδες κλινικών δεδομένων στέλνονται με `Cache-Control: no-store`.
- Το schema της κλινικής βάσης δεν τροποποιείται από την εφαρμογή.

## Backup

Κατά την πρώτη εκκίνηση κάθε ημέρας δημιουργείται ελεγμένο SQLite backup. Από τις
«Ρυθμίσεις» μπορεί να δημιουργηθεί και χειροκίνητα.

Προεπιλεγμένος φάκελος: `physio_backups`, δίπλα στον φάκελο του project. Διατηρούνται
τα 30 πιο πρόσφατα αντίγραφα. Συνιστάται ο φάκελος να αντιγράφεται και σε δεύτερο,
κρυπτογραφημένο αποθηκευτικό μέσο.

## Επιλογή άλλης βάσης

Windows PowerShell:

```powershell
$env:PHYSIO_DB_PATH="C:\path\to\physio_new.db"
$env:PHYSIO_META_PATH="C:\path\to\physio_app_meta.db"
$env:PHYSIO_BACKUP_DIR="D:\PhysioBackups"
.\.venv\Scripts\python.exe run.py
```

Linux:

```bash
PHYSIO_DB_PATH=/path/physio_new.db \
PHYSIO_META_PATH=/path/physio_app_meta.db \
PHYSIO_BACKUP_DIR=/safe/backups \
.venv/bin/python run.py
```

Αν δεν οριστεί `PHYSIO_META_PATH`, κάθε εξωτερική κλινική βάση αποκτά δικό της
`<όνομα>_app_meta.db`. Έτσι το Undo δεν μεταφέρεται σε διαφορετική βάση.

## Βασικές λειτουργίες

- Ενεργά και ανενεργά ιστορικά.
- Νέος/υφιστάμενος ασθενής και ιστορικό.
- ΑΥΤΟΣ, συνεδρίες και οικονομικά.
- Αυτόματη αποθήκευση υπαρχουσών εγγραφών με οπτική ένδειξη σφάλματος.
- Αυτόματη συμπλήρωση από πραγματικές παλαιότερες τιμές στις φόρμες νέου ασθενούς και ιστορικού.
- Προειδοποίηση πριν από έξοδο από φόρμα με μη αποθηκευμένες αλλαγές.
- Επιβεβαιωμένο Undo με `Esc` ή από τη γραμμή πλοήγησης.
- Ελληνική αναζήτηση χωρίς διάκριση πεζών/κεφαλαίων και τόνων.
- Συνεχείς λίστες με αυτόματη φόρτωση batches και server-side αναζήτηση/ταξινόμηση.
- Προσβάσιμη ταξινόμηση από τις επικεφαλίδες με βέλη κατεύθυνσης.
- Responsive μενού και διάταξη για κινητές συσκευές.
- Έλεγχος υγείας δεδομένων και backup από τις «Ρυθμίσεις».

## Tests

Τα tests χρησιμοποιούν μόνο προσωρινές βάσεις:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Git

Το `.gitignore` αποκλείει `.venv`, SQLite αρχεία, backups και logs. Μην προσθέτετε
ποτέ κλινική βάση ή backup σε repository.
